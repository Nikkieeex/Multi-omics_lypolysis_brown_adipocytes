# Omics project logbooks

This GitHub repository is made for the omics project. In this repository there are four individual logbooks from the group members. In these logbooks the code and the work that each person did during the project is written down.

## Goal of this repository

The goal of this GitHub page is to keep the project work clear and reproducible. By saving the code and the explanation of the steps, it is possible to see what has been done during the project and who worked on which part.

The repository contains four individual logbooks. Each logbook describes the own part of one group member in the project. These logbooks show the used code, the performed steps and sometimes also the choices that were made during the analysis.

## Content of the repository

In this repository you can find:

- Four individual logbooks from the group members
- The code that was used during the project
- Explanations of the performed steps
- Notes about choices that were made during the analysis
- Results and intermediate results from the bioinformatics workflow

## Background of the project

In the omics project biological data is analysed with bioinformatics methods. During this project different steps are needed to check, process and interpret the data. The logbooks show how these steps were performed in practice.

## Use of the logbooks

The logbooks can be used to:

- Read back the performed analyses
- Check or repeat the used code
- See the task division within the group
- Understand which choices were made during the project
- Support the reproducibility of the project

## Note

This repository is meant as project documentation. The logbooks were written during the project, so they show both the final analyses and the work process.
